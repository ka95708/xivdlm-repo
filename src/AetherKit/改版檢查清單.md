# 改版檢查清單

遊戲或 FFXIVClientStructs 改版後，**先檢查這裡列的功能**。它們直接寫遊戲記憶體、呼叫或攔截遊戲函式，結構位移或函式特徵一變就可能寫錯位置、攔錯函式，後果比一般「按鈕按不到」嚴重（可能當機或改到別的值）。

AetherKit 的原則：盡量透過遊戲介面操作；只有沒有可行的介面做法時才改記憶體。加了新的，就把它加進這份清單，並在程式碼那一行附近加上註解標記 `[改記憶體]`、`[遊戲函式]` 或 `[Hook]`，用搜尋就能全部找到：

```powershell
rg -n "\[改記憶體\]|\[遊戲函式\]|\[Hook\]" src/AetherKit
```

## 直接寫記憶體

| 功能 | 位置 | 寫了什麼 | 改版時確認 |
|---|---|---|---|
| 核心：任務搜尋器設定（備用） | `Core/DutyFinderSettings.cs` `ApplyDirectly` | 找不到套用函式時，直接改 `ContentsFinder` 的選項欄位與 UiConfig | 平常不會走到；log／core log 出現「找不到套用函式」才代表在用它 |
| 任務搜尋器快速設定 | `Tweaks/DutyFinderQuickSettings.cs` `SetNativeIcons` | 藏起任務搜尋器原本的設定圖示（節點 6），關掉小功能時還原 | 開著時原本的小圖示不見、換成可點的一排；圖示位置沒有偏掉 |
| 自動雇員：價格表 | `Game/RetainerWork.cs` `SetNativeSellList` | 價格表開著時藏起遊戲出售清單（`RetainerSellList`）的根節點，關掉價格表、卸載時還原 | 價格表開著時原本的清單看不到、滑鼠移過價格表不會跳物品資訊；收起價格表後原本的清單回來 |
| 確認框預設選「是」 | `Tweaks/AlwaysYes.cs` `Focus` | 確認視窗打開時呼叫 `SetFocusNode` 並寫 `CursorTarget`；各視窗「是」按鈕的節點編號寫死（照 Simple Tweaks） | 打開一般確認框、分解確認，游標在「是」上；節點編號對不上時游標不會動 |
| 更多貨幣顯示 | `Game/CurrencyDisplay.cs` `Build`／`Remove` | 在金幣視窗（`_Money`）建圖示、數字節點並接進節點樹（同 Simple Tweaks）；數字節點借用金幣那一列（節點 2）的數字圖片、位置照圖示（節點 3） | 右下角金幣上方（或下方）多出設定的幾列，圖示、數字樣式跟金幣一樣；開關 HUD 版面配置、停用模組幾次不會當機 |
| 仙人微彩 | `Tweaks/MiniCactpot.cs` | 仙人微彩視窗上「選中的線」（`AddonLotteryDaily.UnkNumber3D4`），讓畫面上的選取跟送出的線一致 | 自動選線後，畫面上亮的線就是聊天欄說的那條 |
| 鏡頭最大距離 | `Tweaks/CameraMaxDistance.cs` `Apply` | 鏡頭（`CameraManager.GetActiveCamera()`）的 `MaxDistance`，開著時每幀不一樣就寫回設定值，關掉時改回 20（同 Cammy） | 滾輪能拉到設定的距離；換地圖、過場後還是一樣遠；關掉後只能拉到預設距離 |
| 物品持有提示 | `Game/OwnershipTooltip.cs` `CreateNode`／移除節點 | 在物品資訊框裡建立文字節點、接進節點串列，關掉時再拆掉 | 滑過物品時提示正常出現、資訊框沒有跑版，開關幾次不會當機 |
| 無人島：工房套用排班 | `Game/CraftworksApplier.cs` `SetRestCycles`、`RefreshUi` | 排班代理的 `ScheduleData.NewRestCycles`（新的休息日遮罩）、`Flags1 |= 4`（讓排班表重新整理），同 visland | 套用後排班表的休息日跟 AetherKit 排的一樣；畫面有更新、不用關掉重開 |
| 隱藏其他人 | `Game/HideOthers.cs` `Hide`／`Show` | 其他玩家、召喚物、陸行鳥、小寵物的 `GameObject.RenderFlags` 加上／拿掉 Model（2）＋Nameplate（2048）位元（同 Visibility）；只拿掉自己加過的物件 | 啟用模組後其他人和名牌都不見、自己的寵物還在；停用模組後全部回來；位元值以 FFXIVClientStructs 的 `VisibilityFlags` 為準 |

## 直接呼叫遊戲函式

不經過視窗，直接呼叫遊戲內部函式。

| 功能 | 位置 | 呼叫什麼 | 改版時確認 |
|---|---|---|---|
| 核心：任務搜尋器設定（青魔教皇、任務搜尋器快速設定共用） | `Core/DutyFinderSettings.cs` `ApplySignature` | **特徵碼**找遊戲「套用任務搜尋器設定」的函式（同 DR），改版最容易壞 | 點快速設定的圖示，任務搜尋器的「設定」視窗裡跟著變；log 寫的是「遊戲函式」不是「直接改值」 |
| 自動雇員：查市場 | `Game/RetainerWork.cs` `RequestMarket` | `InfoProxyItemSearch`：先改 `SearchItemId`、`EntryCount`（也算改記憶體）再 `RequestData`（同 DR） | 改價時 log 每件都有「市場最低 N」，沒有一直「市場資料沒有回來」 |
| 自動雇員：改價 | `Game/RetainerWork.cs` `SetPrice` | `InventoryManager.SetRetainerMarketPrice`（同 DR；價格表、全部改價共用），改完用 `GetRetainerMarketPrice` 讀回來確認 | log／聊天欄沒有「讀回來是 N，可能沒改成功」；重開出售清單價格跟改的一樣 |
| 自動雇員：全部收回給自己 | `Game/RetainerWork.cs` `RetrieveToInventory` | `InventoryManager.MoveFromRetainerMarketToPlayerInventory`（同 DR） | 按了之後出售清單一件件消失、背包多出來；log 沒有「收不回來」 |
| 自動雇員：存入重複物品 | `Game/RetainerWork.cs` `OpenItemMenu` | `AgentInventoryContext.OpenForItemSlot`：對背包格子開右鍵選單，再照文字點「交給僱員保管」（Addon 97）；讀 `ItemFinderModule` 的雇員快取挑雇員 | 雇員清單按「存入重複物品」，log 每件有「存入 …」，沒有「打不開右鍵選單」「右鍵選單沒有…」 |
| 高山茶理符：領理符 | `Game/TsaiTouVounouLeve.cs` `SendAccept` | 理符視窗（`GuildLeve`）開著時對 `AgentLeveQuest` 送事件 `[3, 理符編號]`（同 DR），不點清單 | log 有「領了 … 限額 N→N-1」，沒有「沒有領到（第 N 次）」 |
| 無人島採集：讀庫存 | `Game/IslandPouch.cs` `Materials`、`Counts`、`CountOfRow` | `AgentMJIPouch.GetPouchItemCount`（只讀，MJIItemPouch 的列號）：庫存目標、採到什麼、穀倉會不會超過 999 | 在無人島開「庫存目標」分頁，數量跟無人島背包視窗一樣；採集時 log 有「採了 … ：無人島…+N」 |
| 無人島：工房讀資料 | `Game/Craftworks.cs` `RequestData`、`Read` | 排班表打開時 `MJIManager.RequestDemandFull`、`RequestFavorData`（跟伺服器要今天的供需、貓耳小員）；之後只讀 `MJIManager` 的 `SupplyAndDemandShifts`（高 4 位元供給、低 4 位元需求變動）、`CurrentPopularity`、`CurrentGroove`、`CurrentCycleDay`、`IslandState.Workshops`、`FavorState`（第 3～5 格本週、6～8 格下週） | 模組頁「需求與趨勢」的供給、需求變動跟遊戲排班表「需求」頁一樣；頁首的幹勁、工坊數、等級正確 |
| 無人島：工房套用排班 | `Game/CraftworksApplier.cs` `Apply` | 排班表開著時：`AgentMJICraftSchedule.SetDisplayedCycle`（切到某天）、排班代理事件 6（清空那天）、事件 5（確認休息日）、`MJIManager.ScheduleCraft(產品, (小時+17)%24, 第幾天, 第幾間)`（同 visland） | 按「套用」後排班表每天、每間工坊的產品和順序跟 AetherKit 顯示的一樣；craftworks log 有每天一行 |
| 無人島：開拓穀倉領取並派遣 | `Game/IslandFacilities.cs` `CollectAndDispatchGranaries`、`Dispatch` | 穀倉視窗開著時：`MJIGranariesState.CollectResources`（領取）、`AgentMJIGatheringHouse.IsExpeditionUnlocked`（只讀）、先填 `AgentMJIGatheringHouse` 的 `CurGranaryIndex`／`CurSelected*`／`ConfirmType` 等欄位（改記憶體）再 `SelectExpeditionCommit`（派遣，同 visland） | 按「領取並派遣」後兩個穀倉的資源進背包、探險地點換成稀有資源最少的、剩餘天數變 7；island-granary log 每個穀倉一行，青船幣有扣 |
| 青魔教皇 | `Game/BlueMageVaultFarm.cs` `QueueDuty` | `ContentsFinderQueueInfo.QueueDuties`：排教皇廳（位址由 FFXIVClientStructs 提供） | log 出現「排隊（第 1 次，排隊函式）」之後就開始配對，沒有「沒有進入排隊」 |
